# Calculator Git Hooks

This project is a simple Python calculator created to demonstrate the use of Git hooks.

## Project structure

- `src/calculator.py` - source code
- `tests/test_calculator.py` - unit tests
- `README.md` - project description
- `requirements.txt` - required tools
- `.gitignore` - ignored files

## Implemented functions

- add
- subtract
- multiply
- divide
- power
- factorial
- is_even

## Testing

Run unit tests with:

```bash
python -m unittest discover tests 
```
